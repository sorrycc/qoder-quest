# 这个项目的规矩 / Rules for this project

这里只做一张落地页，投资人几分钟后就到。

- 纯前端：一个 `index.html`，放在当前目录，CSS 和 JS 都写在这个文件里。
- 不要后端、不要 functions、不要数据库、不要框架、不要构建工具、不要 `npm install`。
- 不要另建 `web/`、`dev/` 之类的目录结构，双击 `index.html` 就能打开。
- 图片和视频用相对路径引用。

This is a single landing page and the investor is minutes away.

- Frontend only: one `index.html` in the current folder, with its CSS and JS inline.
- No backend, no functions, no database, no framework, no build tools, no `npm install`.
- No `web/` or `dev/` folder structure. Opening `index.html` by double-click must work.
- Reference images and video by relative path.
